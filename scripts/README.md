# Scripts

A szakdolgozati projekthez használt scripteket tartalmazza.

1. A könyvtár célja

A scripts/ könyvtár a szakdolgozati projekthez készített saját szkripteket tartalmazza. Ezek célja a bioinformatikai munkafolyamat egyes lépéseinek automatizálása, az eredmények összesítése és a reprodukálhatóság támogatása.

A részletes módszertani leírások a docs/ könyvtárban találhatók. A jelenlegi fejlesztés elsődlegesen a MeSS segítségével szimulált közösség, a Flye assembly, a read mapping, a SemiBin2 binning, a CheckM2 minőségellenőrzés és a FastANI/QUAST referencia-alapú értékelés eredményeire épül.
