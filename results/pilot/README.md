# Pilot eredmények

Ez a könyvtár a MeSS-alapú pilot munkafolyamat összesített eredményeit tartalmazza.

**Összehasonlító táblázat**

Az Osszehasonlito_tablazat.xlsx fájl a tíz eredeti referencia-genomhoz kapcsolódó szimulációs és minőségellenőrzési adatokat foglalja össze.

Az összesítés a MeSS szimuláció, a SemiBin2 binning, a CheckM2 minőségellenőrzés, valamint a FastANI- és QUAST-vizsgálatok eredményeire épül.

A táblázat egyetlen, tíz referencia-genomot tartalmazó szimulált ONT-mintából származik.
